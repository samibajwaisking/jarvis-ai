# Changelog

All notable changes are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/) and the project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-19

### Added
- Terminal chat, voice mode and web interface with JSON API.
- Four AI engines: Ollama (free, local), Anthropic Claude, OpenAI and Google Gemini.
- Local SQLite memory for conversation history and notes.
- Built-in skills: help, about, time and date, calculator, notes, web search, system info.
- `jarvis doctor` setup checker and `jarvis guide` tutorial.
- Optional access token for the web API.
- Full documentation, tests, CI workflow and GitHub community files.
